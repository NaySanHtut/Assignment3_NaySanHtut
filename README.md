# Assignment3

## Files
- `array.h` — defines the Array struct
- `main.c` — main program and function implementations

## How to Compile
```bash
gcc -Wall -o main main.c
```

## How to Run
```bash
./main <size>
```
Example:
```bash
./main 6
```

## Notes (personal use for me only)
```bash
"-Wall" isn't needed in gcc but it's good for catching errors. Make a habit using it.
```
